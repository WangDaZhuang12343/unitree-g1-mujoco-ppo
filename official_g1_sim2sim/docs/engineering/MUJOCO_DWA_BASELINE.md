# MuJoCo / DWA 冻结基准

基线提交：`0c191e2`。DWA是当前默认规划器、未来RL baseline与fallback。数字来自仓库固化报告。

## 固定运行合同

### 感知与地图

- 深度相机：64×40，水平/垂直FOV 80°/50°，下视20°，最大距离3.5米，10 Hz。
- 地面分割：重力约束RANSAC 80次，阈值0.018米，最大倾角25°，至少80内点且比例≥25%。
- Costmap：0.05米分辨率，前4.0米、后0.5米、左右各2.0米；障碍高度阈值0.035米，膨胀半径0.28米。
- 感知决策不读取MuJoCo geom ID；geom handle仅用于场景更新、碰撞真值与回归对照。

### DWA与安全层

- DWA：`vx=0.25～0.45 m/s`、`|vy|≤0.10 m/s`、`|omega|≤0.20 rad/s`。
- 候选：1个停止候选加`6×5×11=330`个运动候选，共331条；预测10秒，步长0.10秒，半径0.22米。
- SafetySystem再次限幅并限制加速度；高度<0.50米或roll/pitch>0.55 rad触发急停。
- 成功：目标误差≤0.30米、机器人存活、障碍碰撞事件为0。

## 11场景确定性基准

总计8/11成功（72.7%），碰撞事件0。

- 成功：单障碍、双障碍、三障碍、随机箱体、窄通道、宽墙、L墙、动态障碍。
- 失败：U墙、死胡同、迷宫；均存活但超时，说明纯局部DWA缺少全局引导与恢复。

逐场景时间、路径、净空和目标误差以`reports/navigation_benchmark_report.md`为准。

## RL公平对比协议

1. 相同机器人、官方Walking ONNX、PD参数、SafetySystem和速度范围。
2. 相同场景几何、目标、时长、随机种子和动态障碍轨迹。
3. 相同感知语义、频率、动作周期和延迟模型；跨后端差异必须记录。
4. DWA/RL都只输出三维速度，不直接控制关节或绕过安全层。
5. 主要指标：成功率、95% Wilson区间、碰撞episode率、碰撞事件、跌倒率、超时率。
6. 次要指标：到达时间、路径长度、最小净空、最终误差、推理延迟和FPS。
7. 先跑11场景诊断，再跑相同100次Monte Carlo；不得只报告成功子集。
8. fallback介入需计数，并分别报告纯RL和RL+fallback成功率。

未来实验不得覆盖原报告。新结果须记录Git提交、配置/模型哈希、随机种子、训练步数和后端版本。
