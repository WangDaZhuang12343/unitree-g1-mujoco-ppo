# 模仿学习失败分析

## 实验证据

| 数据/模型 | 规模或结果 |
|---|---|
| 程序化DWA教师数据 | 800条；600训练、200独立随机验证 |
| DAgger闭环数据 | 500条；单障碍150、双障碍175、窄通道175 |
| 岭回归 | 离线命令MAE 0.0458；闭环0/3 |
| 随机ReLU+距离场 | 离线MAE 0.0457；闭环0/3 |
| 时序随机ReLU | 离线MAE 0.0486；闭环0/3 |
| DWA对照 | 相同单/双障碍与窄通道3/3成功 |

时序模型把单障碍最终距离从4.49米改善到3.70米、双障碍从4.90米改善到3.53米，但仍未到达。零碰撞主要来自保守停滞，不能视为成功。

## 数据充分性

结论：已有数据足以验证训练、加载、安全适配和评估管线，不足以训练可泛化闭环策略。

1. **规模与独立性不足。** 800条独立局部地图是稀疏静态切片；500条DAgger来自3条失败轨迹，有效独立状态远少于样本行数。
2. **场景覆盖窄。** DAgger未覆盖宽墙、L/U墙、死胡同、迷宫、动态障碍和Monte Carlo随机地图。
3. **缺少传感器域随机化。** 教师数据直接构造Costmap，没有深度缺测、RANSAC误差、外参偏差、延迟和动态观测噪声。
4. **标签是单步DWA动作。** 相似局部观测在不同历史、拓扑和恢复阶段可能需要不同动作，回归会平均成低速或弱转向。
5. **DAgger仍非闭环目标。** 重标注修正访问分布，但动作MAE不直接优化到达、碰撞、进度或摆脱局部极小值。

## 输入特征问题

- 初版只有二值占据图与局部目标；加入距离场仅小幅改善离线指标。
- 10×15或6×9池化丢失窄间隙、边缘和障碍拓扑。
- 单帧模型缺少速度、命令响应、感知置信度和延迟。
- 时序模型只有相邻差分与上一命令，没有长期记忆、全局路径、探索或恢复状态。
- 训练输入与真实`Depth→RANSAC→Costmap`链存在分布差异。

## 模型与训练问题

- 岭回归会把DWA离散候选选择平均化。
- 随机ReLU投影不保证保留导航拓扑。
- DWA标签含0与最低连续步速约0.25 m/s的非连续区间，回归容易落入Walking Policy低速死区。
- teacher forcing时序训练在推理时使用自身上一输出，仍有暴露偏差。
- 没有价值函数、优势估计、课程学习、长期绕行与失败恢复目标。

## 评价指标问题

- 离线动作MAE与闭环成功弱相关：三类模型MAE约0.046～0.049，但均0/3。
- 安全否决率低只说明短视轨迹未立即碰撞，不说明能到达。
- 零碰撞必须与到达率、超时率、进度和停滞时长联合报告。
- 3场景只是接入门槛，不能替代11场景和100次Monte Carlo置信区间。

## 未来强化学习必须避免

1. 观测来自完整感知链，或加入等价噪声、延迟与域随机化。
2. Reward同时约束进度、成功、碰撞、跌倒、停滞、净空和平滑；安全/成功优先级最高。
3. 课程从单障碍扩展到多障碍、凹形局部极小值、动态障碍与随机地图。
4. 明确建模Walking低速死区、动作保持周期和控制延迟。
5. 训练、验证、测试场景与种子隔离；使用测试场景DAgger后不得再宣称未见泛化。
6. 每个策略与DWA使用相同底层步态、安全层、场景和成功判据，并报告Wilson区间。
