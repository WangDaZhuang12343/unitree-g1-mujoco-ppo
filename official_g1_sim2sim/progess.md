# 项目进度

更新时间：2026-08-05 17:04 CST

## 阶段总结

当前已完成从“官方 G1 平地行走策略验证”到“纯仿真深度视觉自主绕障”的首个闭环。系统不重新训练底层步态，而是用仿真深度相机感知障碍，经局部代价地图和 DWA 规划生成速度指令，再交给 Unitree 官方 ONNX 策略驱动 29 个关节行走。

当前代码全部为纯 MuJoCo 仿真，不初始化 DDS、不发布 `LowCmd`、不连接真实机器人，也不修改办公电脑的系统 Python 环境。

### 当前数据流

```text
MuJoCo mj_multiRay 深度相机
  → 机器人局部坐标点云
  → 局部占据代价地图
  → DWA 局部规划
  → (vx, vy, omega) 速度指令
  → Unitree 官方 G1 ONNX 策略
  → 动作缩放 + 默认关节位置 + 关节映射 + PD 力矩控制
```

## 当前结论

旧自研 PPO 策略已停止追加训练。新方案直接使用 Unitree 官方预训练策略，本机只负责 CPU MuJoCo 验证，因此不需要 NVIDIA GPU，也不会占用办公软件所依赖的系统 Python 环境。

官方速度策略在 0.25 至 0.70 米/秒范围内表现稳定，速度跟踪误差约为 0.03 至 0.04 米/秒。0.10 米/秒指令没有形成连续步态，属于当前预训练策略的低速死区，后续可通过命令整形或针对性微调处理。

高速直行仍有横向漂移：0.45 米/秒测试末端横移约 0.39 米、偏航约 -2 度；0.70 米/秒测试末端横移约 1.22 米、偏航约 -10 度。当前结论是“官方策略仿真行走基线通过”，不是“可以直接上实机”。后续需区分偏航累积、接触参数差异和模型不对称等原因。

## 当前能力边界

- 现在是仿真深度视觉，不是 RGB 目标识别，也没有接入真机摄像头。
- 绕障规划不读取障碍物真值位置，地面剔除已改为重力约束 RANSAC；真机前仍需用 RealSense 实测噪声、标定误差和缺测帧。
- 已完成 11 类场景的首次确定性基线，但每个场景只运行 1 次；尚未完成参数扫描、100 次 Monte Carlo 或未知环境泛化验证。
- 底层策略不含 height scan，当前方案主要是“绕开障碍”，不具备可靠的抬脚跨越或楼梯能力。
- 现阶段结果不能直接用于真机，真机部署前还需要传感器标定、时延测试、独立急停、限幅、吊装保护和分阶段验收。
