### 当前数据流

```text
MuJoCo mj_multiRay 深度相机
  → 机器人局部坐标点云
  → 局部占据代价地图
  → DWA 局部规划
  → (vx, vy, omega) 速度指令
  → Unitree 官方 G1 ONNX 策略
  → 动作缩放 + 默认关节位置 + 关节映射 + PD 力矩控制
```

## 当前结论

旧自研 PPO 策略已停止追加训练。新方案直接使用 Unitree 官方预训练策略，本机只负责 CPU MuJoCo 验证，因此不需要 NVIDIA GPU，也不会占用办公软件所依赖的系统 Python 环境。

官方速度策略在 0.25 至 0.70 米/秒范围内表现稳定，速度跟踪误差约为 0.03 至 0.04 米/秒。0.10 米/秒指令没有形成连续步态，属于当前预训练策略的低速死区，后续可通过命令整形或针对性微调处理。

高速直行仍有横向漂移：0.45 米/秒测试末端横移约 0.39 米、偏航约 -2 度；0.70 米/秒测试末端横移约 1.22 米、偏航约 -10 度。当前结论是“官方策略仿真行走基线通过”，不是“可以直接上实机”。后续需区分偏航累积、接触参数差异和模型不对称等原因。

- 底层策略不含 height scan，当前方案主要是“绕开障碍”，不具备可靠的抬脚跨越或楼梯能力。
